神奈川御朱印指南：镰仓、江之岛与箱根寺社印章路线

Last updated: April 8, 2026

神奈川拥有日本历史分量最重的御朱印目的地——镰仓单独一处就有超过65座寺社，相互步行可及。与京都知名朝圣路线不同，镰仓的御朱印路线在工作日早晨仍然真正安静，覚園寺岩窟、圆觉寺内院、报国寺竹林无论何时都很少拥挤。

什么是御朱印？

御朱印（ごしゅいん）是朱印（红色印章）与手写书法的结合——寺社名称、供奉的神佛、日期，以及常见的佛偈——由印章受付处（朱印所）的僧侣或神职人员当场书写。每一本都独一无二。收集御朱印需要一本御朱印帳（折叠式手风琴型册子）。

在镰仓购买御朱印帳：

  • 鶴岡八幡宮出售神社专属设计册（¥1,500至2,000）
  • 长谷寺出售白封面、以观音为主题的御朱印帳（¥1,500）
  • 镰仓站内便利店有通用款，¥1,000起

递交御朱印帳时，翻开到空白对页，安静等候，归还时道谢（ありがとうございました）。领取御朱印前先参拜主殿——御朱印是朝圣记录，不是纪念品。

鶴岡八幡宮 — 镰仓的精神中心

交通： 镰仓站步行10分钟（段葛参道直线延伸） 御朱印受付时间： 8:30至16:30 价格： ¥500 宗教： 神道；创建于1063年；源氏家族守护神社；镰仓幕府精神核心 御朱印设计： 粗笔写就的「鶴岡八幡宮」五字，配以巴纹（巴）印章——神奈川最有力量感的设计之一

稀有附加御朱印： 正门进入后左侧的若宫（附属神社）单独发行一种御朱印——小巧、精确，只有资深御朱印收藏者知晓其存在。可询问工作人员。

高徳院 — 镰仓大佛

交通： 江之电长谷站步行10分钟 御朱印受付时间： 8:00至16:30 价格： ¥300（另需¥300寺院入场费；内部参观¥20） 宗教： 佛教（净土宗）；建立于1243年左右；镰仓大佛（国宝） 御朱印设计： 「阿弥陀如来」配以结印中铜像的印章，笔触圆润，印章以佛光为参照

13.35米大佛原本在大型木造堂内，1334年被海啸摧毁后变为现今的露天状态。御朱印记录你对阿弥陀如来的参拜。印章的圆弧形与大佛光背呼应。

内部另有御朱印： 铜像内部（进入背部下方小门后）在特定日期提供附加印章，可询问工作人员——并非每次开放。

長谷寺 — 三种御朱印的寺院

交通： 江之电长谷站步行5分钟 御朱印受付时间： 8:00至17:00（10月至3月至16:30） 价格： ¥300（另需¥400入场费） 宗教： 佛教（净土宗）；建立于736年；主尊为十一面观音（11面观世音，9.18米） 御朱印设计： 「大悲殿」（大悲之殿）配以莲花印章

长谷寺是镰仓园林最丰富的寺院，山丘上的庭园直面由比浜海滩，有观景台与小型龟池。观音像是日本最大的木造佛像之一。

长谷寺的三种御朱印：

  1. 主殿（観音堂）御朱印 — 最标准的版本
  2. 阿弥陀堂（稍下方的阿弥陀殿）— 独立印章
  3. 弁天窟洞窟（供奉弁才天的地下回廊）— 最稀有，不被广泛知晓

建長寺 — 日本最初的禅院

交通： 北镰仓站步行15分钟 御朱印受付时间： 8:30至16:30 价格： ¥300（另需¥500入场费） 宗教： 佛教（临济宗）；建立于1253年；日本第一座正规禅寺 御朱印设计： 「建長禅寺」配以山型印——笔触刻意采用禅宗极简精神的端正字体

后山小道（天空の鳥居）： 寺院后方有山道攀升至一座小山顶鸟居，再前行可抵达源氏山公园（步行约45分钟）。沿途穿越杉林与竹林，若干小型附属社偶有自己的印章，可在建长寺主受付处询问山道受付是否开放。

円覚寺 — 抵御蒙古入侵的禅刹

交通： 北镰仓站步行2分钟（JR横须贺线穿越寺院外院） 御朱印受付时间： 8:00至16:30 价格： ¥300（另需¥500入场费） 宗教： 佛教（临济宗）；1282年为悼念蒙古袭来（1274・1281年）战死者而创建 御朱印设计： 「洪鐘」（洪钟）图案或「円覚寺」主印——两种均可选

圆觉寺是镰仓五山第二位，创建动机特殊——专门为蒙古入侵的亡者祈冥。参道横越JR横须贺线（列车从外院两侧之间通过——日本寺院中绝无仅有的景象）。舎利殿（国宝舍利殿）与洪鐘（国宝，1301年铸）是最重要的存置物。

内院御朱印： 内院的仏日庵（需另付¥100入场费）发行独立御朱印，印章不同。这座小院是第8代禅师无学祖元的私人retreat，平时关闭，开放日可见神奈川最宁静的茶庭之一。

報国寺 — 竹之寺御朱印

交通： 镰仓站东口乘巴士至净明寺站，步行5分钟 御朱印受付时间： 9:00至16:00 价格： ¥200（另需¥500含竹林入场费；茶道体验另加¥600） 宗教： 佛教（临济宗）；建立于1334年 御朱印设计： 「竹の寺」（竹之寺）配以竹叶图案印章——神奈川图案最美的御朱印之一

报国寺主殿后的2,000株孟宗竹林是镰仓最精致的内庭——午后阳光透过竹冠变成绿金色，竹节相击的声音构造出无法拍照记录的氛围。御朱印受付在入口处，竹叶印章是区域内最上镜的设计之一。

竹林内的抹茶时间： 竹林边缘的小茶屋供应抹茶配和菓子（¥600），坐在竹边的榻榻米台上——镰仓最优雅的休息方式。

覚園寺 — 仅限导览的岩窟御朱印

交通： 镰仓站东口乘巴士至大塔宫前，步行10分钟 受付时间： 10:00、11:00、13:00、14:00、15:00（仅限导览，¥700，御朱印含于内） 宗教： 佛教（真言宗）；建立于1218年；药师如来

覚園寺是镰仓最特殊的寺院——唯一需要导览才能进入（全程日语，约30分钟）。路线穿越洞窟佛堂（油灯照明，室町时代以来未变）、榻榻米正殿（原始中世纪药师如来三尊）以及几乎未经时代触碰的林间院落。御朱印在导览过程中由引导法师亲笔书写。

正殿与岩窟内禁止拍照 — 这使覚園寺成为镰仓唯一一处不受手机屏幕干扰、以肉眼纯粹体验的寺院，反而成为记忆最深的一处。

江島神社 — 三社三印

交通： 片濑江ノ島站（小田急）或江之岛站（江之电） 受付时间： 8:30至17:00 价格： 每社¥300（三种），或套餐御朱印¥500 宗教： 神道；供奉弁才天（艺术、音乐、爱情女神）

江岛神社三座连续神社——辺津宫、中津宫、奥津宫——各自发行独立御朱印。三枚构成完整的朝圣套组，收集全部须从岛入口攀登参道约20至30分钟，但每处受付均可无需额外费用参拜。

稀有御朱印： 岩屋洞窟御朱印（洞窟入场费¥500）——岛最深处的洞窟神社——最为罕见，图案为弁才天降服龙的传说，仅在洞窟内才能领取。

箱根神社 — 芦之湖鸟居御朱印

交通： 箱根汤本或小田原乘巴士至元箱根（约60分钟）；或从芦之湖海盗船码头步行约5分钟 受付时间： 9:00至17:00 价格： ¥500 宗教： 神道；创建于757年；主祭神邇邇芸命；旅行者守护神 御朱印设计： 「箱根大神」配以独特双鸟居印章

箱根神社最著名的「平和之鸟居」立于芦之湖中，以富士山为背景——神奈川最被频繁拍摄的景观之一。神社本殿经由90级杉木大道石阶抵达，隐藏在湖边参道之后。御朱印同时使用神社山岳纹样与湖波纹样。

清晨参拜： 湖中鸟居在秋冬晴天清晨5:30至6:30，水面平静、富士山浮现于薄雾之上——御朱印受付9:00才开，但视觉体验在三小时前已经达到顶峰。

推荐御朱印路线

半日路线：镰仓站周边

鶴岡八幡宮 → 步行15分钟 → 乘江之电至长谷 → 高德院 → 步行10分钟 → 长谷寺（可领3种）

4至5枚御朱印，约3至4小时，交通最简便。

全日路线：北镰仓至镰仓

北镰仓站 → 円覚寺 → 步行5分钟 → 建长寺 → 步行20分钟或出租车 → 報国寺 → 出租车/巴士 → 覚園寺（须参加10:00或13:00导览）→ 乘巴士返回镰仓 → 鶴岡八幡宮

5至6枚御朱印，完整一天，适合御朱印资深收藏者。

一泊两日：镰仓→江之岛→箱根

第一天： 镰仓中心（鶴岡、高德院、长谷寺）→ 江之电至江之岛 → 江岛神社三社+岩屋洞窟 第二天： 箱根住宿 → 清晨箱根神社湖中鸟居（5:30至7:00）→ 受付9:00开放领取御朱印

8至9枚御朱印，两日完成。

御朱印礼仪

  • 先参拜主殿：神道神社先拍手两次、鞠躬；佛寺先合掌敲磬，然后再去受付
  • 现金支付，准备零钱：多数受付无法找零大面额纸币，建议带¥500硬币或小面额
  • 一页一印：御朱印帳翻开到空白对页递交，勿折叠或压缩页面
  • 佛寺与神社可用同一本册，但传统上分开使用——不作硬性规定，但表达对神佛分类的尊重
  • 覚園寺限定导览：无法自行进入，导览时间固定，大门平时关闭，须提前5至10分钟到达
