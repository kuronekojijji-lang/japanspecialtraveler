Comiket同人展攻略：日期·入場·東京Big Sight·海外參加

Last updated: May 23, 2026

每年兩次，動漫及漫畫世界嘅目光都會聚焦喺東京灣海濱一批充滿未來感嘅建築上。三日之內，超過70萬名粉絲湧入東京Big Sight參加 Comiket——全球最大嘅自費出版媒體市集，逾30,000個獨立創作者團體（社團）直接向買家出售自己原創嘅漫畫、畫集、遊戲，以及音樂。如果秋葉原係動漫文化嘅永久家園，Comiket就係佢跳動嘅心臟。

對海外訪客嚟說，Comiket亦係東京最令人望而生畏嘅活動之一——規模龐大、人潮洶湧、幾乎全程以日文進行，需要認真準備先可以好好享受。本指南涵蓋你所需了解嘅一切。

⚠️ 夏季Comiket熱浪警告——請先睇呢段

東京8月氣溫通常達到 34–38°C，濕度70–80%。戶外排隊區係暴曬嘅混凝土地面，完全沒有遮蔭，每個夏季場都有數十名參加者接受中暑治療。飲水不足、沒有補充電解質、穿牛仔褲，以及唔食早餐係四個最常見嘅錯誤——全部都係可以預防嘅。

在其他一切之前，請先跳到 → 生存夏季Comiket 。

📋 出發前決策清單

喺離開日本前鎖定呢些決定——大多數一旦到達就無法補救。

✈️ 行程級別決定（提前4至6週）

  • 參加哪個場次？ 夏季（8月中旬）還是冬季（12月下旬）——氣候截然不同
  • 參加哪幾天？ 第1、2或3天——體裁分配通常喺活動前約6至8週確認
  • 機票及酒店已訂好？ 東京住宿喺盂蘭盆節（夏季）提前數月便訂滿
  • 酒店喺臨海線或山手線車站附近 ——減少早上睡眼惺忪時嘅通勤壓力
  • 旅遊保險明確涵蓋中暑/住院治療

📖 目錄及目標（提前3至4週）

  • 取得目錄 ——網上目錄訂閱或購買實體DVD版
  • 確定首要5至10個社團 ——你喺開場後立即要去嘅目標
  • 標記首要20至30個社團以備時間充裕時二次造訪
  • 提交企業區抽籤申請，針對任何必買限定商品（TYPE-MOON、Key等）
  • 記錄備用社團，以防首要目標售罄

🧳 後勤事宜（提前1至2週）

  • 提款計劃 ——了解你銀行嘅每日提款上限，以及哪些日本ATM接受你嘅卡
  • 訂購隨身WiFi或eSIM，用於離線目錄應用程式及地圖
  • 酒店日文地址已複製（酒店名片相片），用於填寫大和運輸送貨單
  • 國際轉運帳號已設立（Tenso/Buyee），以防行李超重
  • 防暑裝備已備好（或記錄酒店附近便利店位置）——冷感毛巾、隨身風扇、鹽糖

🌅 活動前一天

  • 已提款（從7-Eleven ATM提取¥20,000–50,000）
  • 手機已充滿電，充電寶已充滿
  • 目錄應用程式數據已離線下載 ——唔好依賴場館WiFi
  • 列車路線已熟記（搭臨海線，活動當日唔好搭百合海鷗線）
  • 出發時間已設定 ——目標係早上7:00前離開酒店
  • 早餐計劃 ——輕但飽肚；夏天絕對唔好唔食早餐（途中喺便利店買飯糰都可以）
  • 出門前袋入水同運動飲料

🎌 咩係Comiket？

同人誌即賣會（コミックマーケット），通稱 Comiket 或 C 加上其屆次編號，於1975年喺東京創辦。由700名自費出版漫畫迷嘅聚會開始，現在已擴展至數十萬平方米嘅展覽空間，每年舉辦兩次：

  • 夏季Comiket： 8月中旬，日本盂蘭盆節假期期間，連續三天
  • 冬季Comiket： 約12月28至31日，連續三至四天

活動嘅核心係同人誌（どうじんし）——自費出版嘅作品，涵蓋以現有作品為基礎嘅粉絲漫畫，以及完全原創嘅小說、插畫集、小說，以及音樂CD。每個創作者支付社團參加費，獲得一個小攤位（通常係一兩張桌子）直接向買家出售。沒有授權，沒有零售加價，沒有中間人。

喺呢30,000個以上嘅獨立創作者旁邊，企業區（企業ブース）設有主要動漫工作室、遊戲公司，以及出版商，發售限定商品、聯動周邊，以及活動限定產品——形成與社團區並駕齊驅嘅第二大吸引力。

結果就係一個獨特嘅生態系統：精緻嘅商業發行品與親手釘裝嘅影印小冊子，並排喺同一個巨大展館裡出售。

📅 時間及地點：2026年夏季

場地： 東京Big Sight（東京ビッグサイト）
東京都江東區有明3-11-1

2026年夏季Comiket預計喺2026年8月中旬舉辦，大概係8月9至11日或10至12日（日期通常提前4至6個月公布）。請查閱官方網站確認確切日期：www.comiket.co.jp

一般開放時間： 10:00–16:00（東館/西館/南館可能依次開放）。戶外排隊大約從6:00–7:00開始。

旅行規劃重要提示： 夏季Comiket恰逢日本國內旅遊高峰期（盂蘭盆節）。一旦確認日期，請立即預訂機票及酒店——東京住宿喺盂蘭盆節期間提前數月便訂滿。

🚆 前往方法

東京Big Sight喺東京灣有明島上，由東京市中心搭火車約30至40分鐘。

臨海線係Comiket當日最快、最高容量嘅路線。

喺大崎站（由JR山手線轉乘）上車，乘至國際展示場站（こくさいてんじじょうえき）。Big Sight由車站出口步行約7分鐘——跟著人群走就係。

時間貼士： 9:00前出發可在最壞嘅人群湧現前到達Big Sight。無論搭哪條線路，9:30至11:00之間往有明方向嘅列車都會極度擁擠。

📖 出發前嘅準備工作

第一步：取得目錄

Comiket目錄（カタログ）係活動嘅聖經——列出每個社團、佢哋嘅位置、體裁，以及少量作品樣本。

  • 實體目錄（DVD版）： 活動前約六週可在主要書店（Animate、虎之穴、Melonbooks、Mandarake）及便利店（7-Eleven、Lawson、FamilyMart）購買。價格：¥2,500–3,000。包含電腦瀏覽用嘅數據DVD。
  • 網上目錄（ウェブカタログ）： 喺webcatalog.comiket.com 可免費基本瀏覽。付費訂閱（約¥1,500）可解鎖社團標記及路線規劃功能。
  • 手機應用程式： 配套應用程式（iOS/Android）可讓你瀏覽目錄、標記社團，以及規劃路線——活動前先下載，並喺有WiFi時設置好標記。

第二步：做好社團標記

活動當日臨時瀏覽30,000個以上嘅社團係唔實際嘅。出發前：

  1. 瀏覽目錄（按體裁、按日期或按關鍵字），標記所有你想去嘅社團
  2. 記錄每個社團嘅區域代碼——例如「東ヘ-12a」表示東館（東）、H區（ヘ）、12a號攤位
  3. 確定首要5至10個目標：開場後立即前往；熱門社團20至60分鐘內便會售罄
  4. 使用應用程式嘅路線規劃功能有效地安排行程順序

第三步：提款

大多數社團只收現金。部分已採用PayPay或Square讀卡機，但唔可以依賴——請假設所有地方都需要現金。

建議金額：

🗺️ 在場館內導航

東京Big Sight喺Comiket期間使用多個展館。每屆佈局略有不同，但大致結構如下：

東展館（東展示棟）

最大嘅區域，包含大多數同人誌社團。展館按平假名字符分成區塊（甲至末，然後係延伸字符）。每個區塊係一個桌子格局；社團標記地圖會顯示每個社團嘅確切位置。

西展館（西展示棟）

通常設有企業區（企業ブース）的一部分——由主要遊戲公司、動漫工作室，以及出版商運營嘅攤位。視乎每屆情況，也可能用於特定社團體裁。

南展館（南展示棟）

Big Sight較新嘅展館，用於額外社團、特定體裁，或企業展商。請在前往前查閱當屆嘅展館地圖。

按日嘅體裁分配

每天分配特定體裁。傳統模式：

  • 第1及第2天： 女性向體裁——Boys' Love（BL/腐女向け）、女性向粉絲作品、部分一般體裁
  • 第3天： 男性向體裁——萌系、軍事、電玩、部分一般體裁；企業區最繁忙

呢個分配每屆都會改變。 請務必從你所參加嘅具體場次嘅官方目錄或網站確認實際嘅日期分配。

🛍️ 喺社團攤位購買

運作方式

每個社團佔一兩張桌子。已出版嘅作品連同供翻閱嘅樣本（見本——mihon）陳列展示。上前、查看樣本，如果想買，表示你想要哪件商品並支付列明嘅價格。

社團禮儀：

  • 唔好喺桌子旁邊打開或閱讀已購買嘅書——先走開一旁
  • 未有標明價格嘅物品：問「おいくらですか？」（幾錢？）
  • 如果有排隊標柱（針對熱門社團），請加入指定隊伍——唔好直接走近桌子
  • 大型社團可能設有義工隊列工作人員管理獨立等候區
  • 每人通常購買一本；創作者自行設定購買限制

典型價格：

  • 小型同人誌（20至60頁）：¥300–800
  • 標準同人誌（60至200頁）：¥800–1,500
  • 畫集/豪華製作：¥2,000–5,000以上

R-18成人作品（成人向け）

特定展館嘅指定區域包含限制級同人誌。黑色簾幕（黒カーテン）標示邊界。

  • 需要護照 ——工作人員喺R-18區域入口核查年齡
  • 必須達到 18歲或以上（日本法定成人年齡）
  • 請勿掀起簾幕或在沒有購買意圖嘅情況下在內部瀏覽
  • 與一般流通區域分開；請按標示路線前進

🏢 企業區

企業區（企業ブース）係一個自成一體嘅世界——一個集中嘅地帶，主要動漫工作室、遊戲開發商、手辦製造商，以及出版商喺呢度出售限定活動商品。

攻略策略：

  1. 活動前抽籤（事前抽選）： 最受歡迎嘅公司——TYPE-MOON、Key、角川、SEGA、Nitroplus等——會為其限定商品舉辦活動前抽籤。請喺活動前約4至6週開始留意公司官方網站及社交媒體。抽籤登記截止日期通常係活動前2至4週。呢係保證獲得最熱門商品嘅唯一方法。

  2. 當日手環排隊： 當日，多個攤位會喺場館外從7:00至8:00開始發放編號手環（整理券）。先去取目標攤位嘅手環，然後喺指定時間段回來。

  3. 耐力排隊： 對於不發手環嘅攤位，早上高峰時段預計排隊1至3小時。部分旗艦公司嘅隊伍可能更長。下午（14:00至15:00）通常較短——但熱門商品可能已售罄。

  4. 出售商品： 活動限定手辦、限量版畫集、原聲帶CD、商品聯動、即將發售嘅提前版，以及有簽名嘅商品。

📸 喺Comiket Cosplay

Comiket係全球最大嘅Cosplay聚會之一——每日數以千計身穿精心服裝嘅Coser湧入展館之間嘅戶外廣場。

Coser規則

  • 唔可以穿著服裝進入場館。 以便服到達，並使用場館內嘅Cosplay更衣室（コスプレ着替え所）。更換服裝需付費（每次約¥500–800）。
  • 服裝規則： 不可有仿真外觀嘅武器或槍械。道具必須符合指定尺寸。大型翅膀、高聳嘅建構物，以及非常規材料可能需要事先審批——請提前喺Comiket網站查閱每屆詳細嘅Cosplay規則。
  • 離開建築物： 離開場館前（進入出口隊伍、搭乘公共交通回家等），必須換回便服。
  • Cosplay戶外廣場（コスプレ広場）： 東館與西館之間嘅戶外廣場係指定嘅服裝攝影區域。請喺呢度穿著你嘅服裝。

攝影師規則

  • 影相前必須取得Coser同意。 標準用語係「撮影いいですか？」（Satsuei ii desu ka? ——「可以幫我影相嗎？」）。等待點頭或「どうぞ」（請）嘅回應。
  • 喺未取得許可嘅情況下，拍攝社團攤位商品或頁面內容係不被允許——先購買先。
  • 唔好未受邀就跟隨Coser，或未經同意從背後拍攝。
  • 如被要求立即刪除照片——呢係基本禮儀。

💴 付款及郵寄購買品

現金優先

場館內及附近嘅ATM喺繁忙日嘅上午中段便會耗盡現金。7-Eleven ATM網絡係最可靠嘅國際卡提款網絡。請喺活動當日前提款。

大和運輸寄件服務（ヤマト運輸）

Comiket設有官方行李轉寄服務，與大和運輸合作。場館內嘅服務台讓你將購買品裝箱並直接寄往你嘅酒店——隔日送達——這樣你就唔需要拿著所有東西搭火車。

  • 費用： 視乎箱子大小及目的地，約¥1,000–2,000
  • 箱子： 可喺大和服務台購買（每個¥50–200）
  • 流程： 裝箱、填寫寄件單（工作人員可協助日語部分）、付款、獲取追蹤號碼
  • 貼士： 用日文寫下酒店地址——複製酒店名片或訂房確認的相片

對於任何購買量超過一個購物袋所能輕鬆承載嘅人，強烈建議使用呢項服務。

將購買品帶回家（國際）

Comiket場館不設直接國際寄送服務。選項如下：

  1. 從酒店寄送： 東京主要酒店提供日本郵政EMS/SAL國際包裹服務——視乎重量及目的地，通常每件¥2,000–5,000以上
  2. Tenso/Buyee轉運服務： 旅行前先登記以獲取日本郵政地址。將購買品寄往該地址，然後轉寄到你的本國。費用額外，但允許合併多件包裹。
  3. 托運行李： 一整天Comiket嘅購物量可輕鬆超過5至10公斤。出發前查閱航空公司行李限制，考慮提前購買額外行李額（比機場現場購買划算得多）。

🌡️ 生存夏季Comiket——中暑係第1位風險

⚠️ 對8月參加者嚟說，呢係本指南最重要嘅部分。 Comiket嘅中暑唔係假設性嘅風險——每個夏季場都真實發生。每個夏天都有幾名參加者被送院，而大多數情況都係同樣嘅可預防錯誤：飲水不足、無補充電解質、穿牛仔褲，以及唔食早餐。

夏季Comiket恰逢東京最殘酷嘅季節。34至38°C加上70至80%嘅濕度係常態。戶外排隊區——參加者喺展館開放前等候嘅地方——係暴曬嘅混凝土地面，完全沒有遮蔭，輻射熱使感覺溫度比實際氣溫高出許多。

💧 補水：最重要嘅唯一習慣

  • 未感到口渴前先飲水。 喺35°C嘅高溫下，當你感到口渴時，你已經脫水了。
  • 排隊前先備好至少1.5升液體 ——大約一半水、一半電解質飲料（寶礦力/Aquarius）。
  • 極端高溫下電解質比水更重要。 單靠喝水實際上可能通過低鈉血症（危險地低鈉）令熱病惡化。交替飲用：水→運動飲料→水。
  • **OS-1（オーエスワン）**係每間日本藥房及便利店有售嘅醫療級口服補液。前往場館前先買一瓶 ——如果你開始感到不適，將其作為緊急飲品備用。
  • **鹽糖（塩飴，shio-ame）**係每個便利店夏季嘅常備商品，每袋約¥200。往口袋塞一把，排隊時每30至60分鐘吃一粒。
  • 排隊時嘅飲水時間表： 每20至30分鐘飲200至300毫升係大致目標。如果你容易忘記，設定手機計時器。
  • 補水站： 場館內嘅自動販賣機數量充足但需排隊。途中嘅便利店早上7時便完全備貨——到達有明前先補充。

👕 著咩去

  • 輕薄、透氣、淺色面料——吸濕排汗運動面料最理想
  • 速乾衫 ——無論你穿甚麼，都會汗濕透
  • 🚫 8月絕對唔好穿牛仔褲。 呢係外國旅客最常犯嘅錯誤。牛仔布唔透氣，會將熱量困喺腿上——請只穿卡其短褲、運動短褲或速乾褲。
  • 袋中備一件換洗衫 ——午間換上一件乾爽嘅衫，舒適感嘅提升你唔會後悔
  • 喺戶外排隊時唔好穿黑色服裝 ——黑色吸收嘅熱量明顯更多

🤝 互相照顧

如果你係與朋友一起參加，喺排隊時每30分鐘互相確認一次狀況。中暑可能在受害者意識到之前已影響判斷力。留意：說話含糊、煩躁易怒、眼神呆滯、儘管天熱卻停止出汗。立即帶佢們離開陽光。

冬季Comiket注意事項： 問題完全相反——12月下旬嘅戶外排隊溫度喺計入風寒前可低至0至5°C，東京灣吹來嘅凍風猛烈。保暖底衣（HEATTECH）、暖包（カイロ）、保暖帽，以及裝有熱茶或湯嘅保溫壺係必備物品。長時間排隊嘅失溫係真實存在嘅風險。

✅ 規則及禮儀一覽

必須：

  • 無條件遵從排隊工作人員（整理スタッフ）嘅指示
  • 喺展館走道中保持穩定前進——唔好停喺人流中間
  • 影相前詢問同意，尤其係針對Coser
  • 走路靠左（按照日本行人慣例）
  • 以耐心及禮貌對待社團成員——好多人對外國訪客感到欣喜

禁止：

  • 插隊——呢係Comiket最嚴重嘅社交違規
  • 喺存在獨立隊伍嘅情況下直接走近社團桌子
  • 喺社團桌子旁邊打開已購買嘅作品
  • 攜帶大型行李箱或突出嘅背包進入展館人流
  • 未經允許拍攝社團商品、頁面內容或人物
  • 穿著Cosplay服裝到達場館

🎯 首次參加策略：如何規劃你嘅一日

1. 選擇其中一天。 首次參加時，多日參加嘅疲憊程度非常高。選擇體裁分配最符合你興趣嘅那一天。

2. 確定你嘅首要10個社團。 使用目錄應用程式建立路線。最優先嘅目標喺開場後首30分鐘內前往——熱門社團很快便售罄。

3. 喺開場時到達。 如果你有頂級目標，爭取喺8:00至9:00前進入排隊。較輕鬆嘅體驗係11:00至12:00到達——人流較少，但目標可能已售罄。

4. 下午中段前往企業區。 熱門企業攤位嘅早上隊伍可長達2至3小時。14:00後通常明顯縮短——但存貨可能已減少。

5. 計劃好出場時間。 最後90分鐘（約14:30至16:00）嘅出場人流最為密集。如果你14:00時雙腳已累得受不了，通常可以直接走到火車站而無需排隊。等到散場則意味著被10萬人以上嘅人流裹挾而行。

6. Comiket後去秋葉原。 Mandarake、K-Books，以及虎之穴喺秋葉原，通常喺活動結束後24至48小時內開始收到Comiket作品嘅二手版本。第3天傍晚及翌日早上係尋找錯過作品嘅好時機。

Comiket係費力的、令人迷失方向嘅，以及與你之前參加過嘅任何活動都不一樣嘅體驗。佢同時亦係全球最非凡嘅粉絲創意展示之一。喺充分準備、正確裝備，以及願意喺日語環境中摸索嘅情況下，佢嘅回報遠超付出——唔止係珍貴嘅書籍及限定商品，而係置身於某些真正獨一無二嘅事物核心嘅無可言傳嘅感覺。
